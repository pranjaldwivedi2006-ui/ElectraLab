# ⚡ ElectraLab — Virtual Electrical Laboratory

ElectraLab is an interactive virtual electrical engineering laboratory designed to help students understand electrical concepts through simulations, circuit visualizations, and real-time calculations.

Instead of only studying theoretical formulas, students can adjust circuit parameters, observe changes in electrical quantities, and explore how electrical systems behave.

## 🚀 Features

- Interactive electrical experiments
- Real-time electrical calculations
- Circuit visualizations
- Adjustable simulation parameters
- Dark-themed laboratory interface
- 3D energy meter simulation
- Energy consumption and meter calibration analysis
- Responsive dashboard interface

## 🧪 Experiments

### 1. Ohm's Law
Explore the relationship between voltage, current, and resistance by changing circuit parameters and observing calculated values.

### 2. Thevenin's Theorem & Maximum Power Transfer
Explore equivalent circuits, analyze circuit parameters, and investigate load conditions for maximum power transfer.

### 3. Energy Meter Calibration
Simulate energy measurement, observe electrical parameters, and explore meter calibration and error analysis through a 3D interactive workbench.

## ▶️ How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if you don't have it.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. ElectraLab will open in your browser.
